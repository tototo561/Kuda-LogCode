# Annotation Guidelines

## Task
Annotators label:
1. **Useful log** — a log statement that helps identify the root cause.
2. **Semantically equivalent code** — generated code that behaves identically
   to the reference.

## Protocol
- Three annotators with 3+ years of Java/Python experience.
- Independent labeling; disagreements resolved by majority vote.
- Inter-rater agreement: Cohen's kappa.

## Results
- Useful log: kappa = 0.86
- Semantically equivalent code: kappa = 0.83
